[gary4local](https://github.com/betweentwomidnights/gary-localhost-installer) can now run on a linux server without a desktop app. the [v0.7.5 downloads](https://github.com/betweentwomidnights/gary-localhost-installer/releases/tag/v0.7.5) include a terminal console for setting up models, starting services and training SA3 or Carey LoRAs. it shares the desktop app’s LoRA library, so the adapters and training history can stay together.

we tested startup and training on the DGX Spark. the linux x64 build still needs hands-on testing.
